# ⚡ AutoTyper Pro

An intelligent, natural auto-typer featuring human-like keystroke dynamics, code editor awareness (auto-brace and indentation handling), and remote desktop latency optimizations (Getscreen, AnyDesk, TeamViewer, Chrome Remote Desktop, LeetCode, VS Code, Monaco).

Available as both an interactive **Dark Mode Desktop GUI** and a feature-packed **CLI tool**.

---

## 🚀 Features

- **Human-Like Typing Dynamics**: Configurable Words-Per-Minute (WPM), Gaussian timing jitter, and realistic word pauses.
- **Code Editor & Remote Desktop Friendly**:
  - **Auto-Brace Correction**: Automatically cleans up premature closing braces (`{}`) generated by IDE auto-close features (Monaco, VS Code, LeetCode).
  - **Indentation Normalization**: Converts tabs to spaces and manages multi-line indentation so your code isn't double-indented by editors.
  - **Modifier Key Reset**: Periodically releases stuck `Ctrl`, `Alt`, `Shift`, or `Cmd` keys common in remote desktop streaming sessions.
- **Modern GUI (Tkinter)**: Complete visual interface with real-time progress bars, character statistics, countdown timers, and setting toggles.
- **Fail-Safe & Dual Controls**:
  - Global hotkeys: `Insert` or `Ctrl + Enter` to pause/resume, `Esc` to stop immediately.
  - Configurable countdown timer for quick switching into target windows or sessions where global hotkeys are restricted.
  - PyAutoGUI corner fail-safe (move mouse to top-left corner to abort instantly).

## 📁 Repository Structure

Just like `node_modules` in JavaScript/Node.js, Python dependencies and virtual environments should **never** be committed to Git:

| File / Folder | Status | Description |
| :--- | :--- | :--- |
| `autotyper.py` | **Tracked** | CLI entry point and core typing engine |
| `gui.py` | **Tracked** | Modern Tkinter GUI application |
| `input.txt` | **Tracked** | Sample input file for testing |
| `requirements.txt` | **Tracked** | Project dependencies (`pyautogui`, `pynput`) |
| `.gitignore` | **Tracked** | Excludes virtualenv and cache files |
| `README.md` | **Tracked** | Documentation and running instructions |
| `bin/`, `lib/`, `include/`, `pyvenv.cfg` | **Ignored** | Virtual environment files (*Python's `node_modules`*) |
| `__pycache__/`, `*.pyc` | **Ignored** | Compiled Python bytecode cache |

## 🛠️ Requirements & Prerequisites

- **Python**: 3.8 or newer
- **Linux (Debian/Ubuntu)**:
  - Tkinter GUI support:
    ```bash
    sudo apt update && sudo apt install -y python3-tk
    ```
  - *Wayland Note*: Wayland restricts cross-application key listening for security reasons. For hotkey controls (`Insert`, `Ctrl+Enter`), switch to an **X11 / Xorg session** at the login screen, or rely on the built-in **countdown timer** (default: 5 seconds).

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone <your-github-repo-url>.git
   cd autotype
   ```

2. **Create and activate a virtual environment**:
   - On Linux / macOS:
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```
   - On Windows:
     ```bash
     python -m venv .venv
     .venv\Scripts\activate
     ```

3. **Install the dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

## 🎮 How to Run

### 1. Launching the GUI

To launch the graphical interface:

```bash
python gui.py
# or
python autotyper.py --gui
```

- Paste your text or load a file via the **Load File** button.
- Adjust target WPM, jitter, countdown, and editor options.
- Click **▶ Start AutoTyping** and switch to your target window before the countdown finishes.

---

### 2. Launching from the Command Line (CLI)

#### Type from a file:
```bash
python autotyper.py --file input.txt
```

#### Type from inline text:
```bash
python autotyper.py --text "print('Hello, World!')"
```

#### Custom speed and countdown:
```bash
python autotyper.py --file input.txt --wpm 150 --countdown 7
```

## ⚙️ CLI Options & Flags

| Flag | Default | Description |
| :--- | :--- | :--- |
| `--gui` | `False` | Launch interactive Tkinter GUI interface |
| `--file <path>` | `None` | Path to text file to read and type |
| `--text <str>` | `None` | Direct string to type |
| `-c`, `--countdown <sec>` | `5` | Countdown in seconds before auto-typing starts |
| `--wpm <float>` | `200.0` | Target typing speed in words per minute |
| `--jitter <float>` | `0.06` | Ratio of random delay added to simulate human typing (0.0 to 0.5) |
| `--word-pause <sec>` | `0.03` | Extra pause added after spaces to prevent dropped characters |
| `--auto-brace-fix` | `True` | Deletes auto-inserted `}` when typing `{` in code editors |
| `--indent-fix` | `False` | Enables auto-indentation management across new lines |
| `--normalize-tabs` | `False` | Converts tab characters into spaces |
| `--tab-size <int>` | `4` | Number of spaces per tab when normalizing |
| `--mac` | `True` | Target mode for macOS / web editors (avoids Home/End key issues) |
